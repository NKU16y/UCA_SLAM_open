# UCA-SLAM: Tightly Coupled Visual-LiDAR SLAM with DoF-wise Uncertainty-driven Constraint Analysis

## Status

This paper was **accepted and presented at ICRA 2026**, held in **Vienna in June 2026**.

We are currently extending this work for a journal submission.

## Code Availability

The header files are currently available in our [UCA-SLAM-plus repository](https://github.com/NKU16y/UCA-SLAM-plus).

**The complete source code will be released upon acceptance of the journal extension.**

## Introduction

**UCA-SLAM** is a tightly coupled monocular visual–LiDAR SLAM framework that models feature uncertainties, performs DoF-wise uncertainty-driven constraint analysis, and achieves adaptive fusion of visual and LiDAR features based on this analysis.
